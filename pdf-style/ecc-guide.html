00Pehle ye cheezein chahiye

Goal: confirm karo ki teeno tools aapke system par hain. Terminal kholo (Mac par Terminal, Windows par PowerShell) aur chalao:

node --version
git --version
claude --version
TipAgar kisi ka jawab "command not found" aaye, to pehle wo tool install kar lo, phir aage badho.

01Setup chalao (sirf ek command)

≈ 2 min · wizard

Goal: ECC ko ek hi command se install karna.

npx ecc-universal@2.2.3 setup

Wizard kuch sawaal poochega. Personal use ke liye ye chuno:

SawaalKya chunna hai
ScopeGlobal user — har project mein kaam karega
HooksStandard hooks
Last stepConfirm kar do

02Check karo ki install ho gaya

Goal: Claude Code ka naya session kholo (claude) aur likho:

/plugin list
ResultList mein ecc@ecc enabled dikhna chahiye.

BOption B: Claude Code ke andar se install

Ise Step 1 ki jagah use karo, uske saath nahi:

/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc
Dhyaan doSirf ek hi tareeka chuno. Do baar install karne se skills, commands aur hooks duplicate ho jaate hain.

03Apni language ke rules jodo

optional

Goal: plugins ke saath rules nahi aate, isliye jo chahiye unhe khud copy karo:

git clone https://github.com/affaan-m/ECC.git
cd ECC
mkdir -p ~/.claude/rules/ecc
cp -R rules/common ~/.claude/rules/ecc/
cp -R rules/typescript ~/.claude/rules/ecc/
Tiptypescript ki jagah apna stack likho (python, golang, waghera). Shuruaat common aur ek language se karo.

04Ab use karo

Claude Code ke andar:

/ecc:plan "Add login with Google"

Planner agent code likhne se pehle feature ko chhote steps mein tod deta hai.

/ecc:configure-ecc

Baad mein scope ya hook profile badalne ke liye.

Aur try karotdd-workflow skill (pehle tests) aur security review agents. Saare agents aur skills ki poori list README mein hai.

05Koi dikkat? Repair ya remove

Goal: ye commands usi folder se chalao jahan se install kiya tha.

npx ecc-universal@2.2.3 doctor
npx ecc-universal@2.2.3 repair
npx ecc-universal@2.2.3 uninstall --dry-run
npx ecc-universal@2.2.3 uninstall
CommandKya karta hai
doctorSetup check karke problem batata hai
repairToota hua setup theek karta hai
uninstall --dry-runDikhata hai kya hatega, kuch delete nahi karta
uninstallECC ko poori tarah hata deta hai

!Safe raho

Sirf official sourceInstall sirf github.com/affaan-m/ECC, npm package ecc-universal, ya ecc.tools se karo. Author ke mutabik re-uploads aur mirrors mein malware ho sakta hai.
