Setup, step by step

ECC Claude Code ko 71 agents, 314 skills, hooks, rules aur memory deta hai. Banaya hai Affaan Mustafa ne (Anthropic hackathon winner). Numbers Nov 2026 tak ke hain. GitHub: github.com/affaan-m/ECC

00Pehle ye cheezein chahiye

ToolKahan se
Node.js 18+nodejs.org
Gitgit-scm.com
Claude Code 2.1+claude.com/claude-code
node --version
git --version
claude --version

Terminal (Mac) ya PowerShell (Windows) mein chalao. "command not found" aaye to pehle wo tool install karo.

01Setup chalao (sirf ek command)

npx ecc-universal@2.2.3 setup

Wizard kuch sawaal poochega. Personal use ke liye chuno: Global user (har project mein kaam karega), Standard hooks, phir confirm.

02Check karo ki install ho gaya

/plugin list
ResultNaye claude session mein ecc@ecc enabled dikhna chahiye.

BOption B: Claude Code ke andar se

Step 1 ki jagah use karo, uske saath nahi:

/plugin marketplace add https://github.com/affaan-m/ECC
/plugin install ecc@ecc
Dhyaan doSirf ek tareeka chuno. Do baar install karne se skills, commands aur hooks duplicate ho jaate hain.

03Apni language ke rules jodo

optional

Plugins ke saath rules nahi aate, isliye jo chahiye khud copy karo:

git clone https://github.com/affaan-m/ECC.git
cd ECC
mkdir -p ~/.claude/rules/ecc
cp -R rules/common ~/.claude/rules/ecc/
cp -R rules/typescript ~/.claude/rules/ecc/

typescript ki jagah apna stack likho (python, golang, waghera). Shuruaat common + ek language se karo.

04Ab use karo

/ecc:plan "Add login with Google"

Planner agent code se pehle feature ko steps mein todta hai.

/ecc:configure-ecc

Baad mein scope ya hook profile badlo.

Aur try karo: tdd-workflow skill (pehle tests) aur security review agents. Poori list README mein hai.

05Koi dikkat? Repair ya remove

Usi folder se chalao jahan se install kiya tha:

npx ecc-universal@2.2.3 doctor
npx ecc-universal@2.2.3 repair
npx ecc-universal@2.2.3 uninstall --dry-run
npx ecc-universal@2.2.3 uninstall
Safe rahoInstall sirf github.com/affaan-m/ECC, npm package ecc-universal, ya ecc.tools se karo. Author ke mutabik re-uploads aur mirrors mein malware ho sakta hai.
