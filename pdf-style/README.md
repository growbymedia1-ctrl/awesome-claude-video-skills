# jayanttechh PDF house style

Use this design for EVERY jayanttechh PDF (from the JITT'AA lyric-video guide).

- Cover: night `#121014`, gold kicker/byline/dot `#E8A928`, cream headline `#F3E6C8`, Anton big word.
- Pages: white, ink `#151311`, red accent `#D4361F` (section numbers, rule bar, labels, callout bars),
  cream cards `#FAF7EF` border `#EDE7D8`, muted `#75726F`, black code blocks.
- Fonts: Inter (body/headings), Anton (display), Space Mono (labels, footer, code).
- Footer: `jayanttechh · <guide name>` left, page number right.

Render: `node render.js page.html out.pdf` (Playwright Chromium, A4). Example: `ecc-guide.html`.
